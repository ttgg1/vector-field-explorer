Vector Field Explorer

Type a vector field as a formula, then explore it in 2D or 3D with arrows, streamlines, particles and colormaps. Runs on the desktop and in a WebGPU-capable browser.

Download latest release Open the web app

Free and open source · GPL-3.0-only · Linux x86_64, macOS (Intel and Apple Silicon), and Windows x86_64

The same explorer on desktop and in the browser

What you can do

  • Typed formulas

    Enter fields such as (-y, x) or (y, -x, z) in the formula bar.

  • 2D and 3D

    Switch between a flat vector plot and an orbitable 3D field.

  • Arrows, streamlines and particles

    Compare the field's direction with advected traces and motion.

  • Click to seed

    Drop a streamline or a particle burst exactly where you click.

  • Colormaps

    Read magnitude with Viridis, Turbo or a monochrome ramp.

  • Camera presets

    Save and restore views, or explore freely in 3D.

  • Screenshot export

    Save the viewport exactly as it looks, ready for notes or slides.

  • Themes

    Match the app to a dark or light working environment.

Desktop downloads

Every download comes from the latest GitHub release. The archives are built from the same source as the browser app.

Linux x86_64

A single-file AppImage. Make it executable and run it; no installation step.

Download the AppImage

Needs a Vulkan-capable graphics driver. If FUSE 2 is unavailable, run the AppImage with --appimage-extract-and-run.

macOS

.app zips for Intel (x86_64) and Apple Silicon (arm64).

Download for macOS

Unsigned and not notarized. On first launch, approve it in System Settings → Privacy & Security, then choose “Open Anyway”.

Windows x86_64

An unsigned .zip containing vector-field-explorer.exe and the licence and notice files. Extract it and run the executable; no installer.

Download for Windows

Unsigned build. Windows SmartScreen may show “Windows protected your PC”: choose “More info”, then “Run anyway”.

Build from source

The desktop app is a Rust project. Build it with a stable toolchain: 

git clone https://github.com/ttgg1/vector-field-explorer.git
cd vector-field-explorer
cargo build --release
./target/release/vector-field-explorer

The browser build uses Trunk and the wasm32-unknown-unknown target; see scripts/test-web.sh in the repository for the exact steps.

Quick controls

Orbit / pan / zoom
In 3D, left- or right-drag orbits and middle-drag or Shift+right-drag pans. In 2D, left- or right-drag pans. Wheel or pinch zooms in both views.
Reset / fit
R resets the view; F fits the domain.
Seed
Click the viewport to seed according to the Left click setting; S and P seed at the pointer.
Help
F1 or ? toggles the help overlay; Help → Keyboard & mouse opens the full table.
Panels and screenshots
Ctrl+B / Ctrl+P toggle panels; Ctrl+Shift+S exports a screenshot.

Browser support

The web app renders with WebGPU and needs a browser that supports it: Firefox 141+ on Windows, Firefox 145+ on macOS Tahoe ARM, Firefox Nightly on Linux, or Chromium/Edge 113+ where WebGPU is available. If WebGPU is missing, the web app's unsupported-browser panel explains how to enable it. Prefer a desktop build? Use the downloads above, or read the in-app help and keyboard reference in the browser.
