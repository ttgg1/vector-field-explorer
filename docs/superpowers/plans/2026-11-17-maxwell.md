# Maxwell Teaching Cases Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bounded Maxwell teaching mode with a canonical analytic catalog and one explicitly approximate 2D infinite-cylinder BEM conductor case, rendered through the existing vector scene seam with honest assumptions, accuracy status, persistence and export warnings.

**Architecture:** `src/maxwell.rs` owns scene validation, analytic fields, outlines, sampling and warnings; a small bounded direct BEM solver handles the two supported 2D conductor outlines. `FieldMode::Maxwell` adds a static vector adapter whose durable scene and cached BEM solution live in `State`, whose app branch paints arrows plus outline lines, and whose responsive panel edits drafts. Persistence and export extend the established request-time provenance path.

**Tech Stack:** Rust 2024, glam f32/f64, egui/eframe, existing `PlaneFrame`/`SceneGPU`/`ViewCommand`/persistence/export seams, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-17-maxwell-design.md`

## Global Constraints

- Teaching-grade, native + wasm, pure CPU; no new dependencies, CLI extension, GPU solver, or private clock.
- Dedicated `FieldMode::Maxwell`; not a source kind; canonical analytic cases do not replace finite source semantics.
- E and B are separate physical outputs; never summed or presented as one vector.
- Display-only normalized amplitudes; UI/export must not claim SI units or a unit engine.
- Only Circle and Square 2D BEM outlines; max 256 fine elements, grounded isolated-neutral infinite-cylinder approximation, explicitly labeled.
- No 3D BEM/FEM, arbitrary CSG, full-wave/FDTD, displacement current/radiation, nonlinear/anisotropic/retarded media, or manufactured solver dependency.
- Default-off opt-in only for finite `AccuracyNotMet`; never override caps or draw NaN/Inf; unavailable/invalid never appears valid.
- 3D caps `MAXWELL_MAX_DENSITY_3D=40`; 2D `MAXWELL_MAX_DENSITY_2D=200`; exact-interface omissions and warnings per design.
- Tests in `tests/`, registered in `tests/suite.rs`; no inline `#[cfg(test)]` in `src/`.
- Browser/manual visual gates owner-waived, not passed. Only known `nom 1.2.4` warning.

## Review Focus

1. **BEM truthfulness:** grounded exterior solve must reject net-charge residual, never compare identical coarse/fine runs, and never report `TargetMet` for an unresolved square corner.
2. **2D projection:** azimuthal fields in a plane containing the axis must omit near-zero arrows and warn; no full-vector equality claim.
3. **Image-plane singularity:** never evaluate the real charge at its center or the unsupported half-space; the z=0 ground slice must be visibly empty, not silently blank.
4. **Extreme finite values:** omit/count/warn above `MAXWELL_MAX_RELATIVE`; never clamp into plausible arrows.
5. **Cache lifecycle:** BEM solve must not repeat on sampling/plane/camera changes; only a scene/geometry edit invalidates it.
6. **Mode isolation:** Maxwell must not consume the clock, particles, streamlines, clicks, or source glyphs, and must preserve other durable scenes/camera.

#[test]
fn grounded_circle_solve_matches_the_dipole_far_field() {
    let scene = bem(MaxwellCase::Conductor2D);
    let solution = solve_bem(&scene).expect("circle BEM");
    let p = Vec3::new(4.0, 0.0, 0.0);

#[test]
fn square_refines_globally_and_never_reports_identical_coarse_fine() {
    let mut scene = bem(MaxwellCase::Conductor2D);
    scene.outline = ConductorOutline::Square { half_extent: 1.0 };
    scene.elements = 64;
    let solution = solve_bem(&scene).expect("square BEM");
    let convergence = solution.convergence();
    assert_eq!(convergence.coarse_elements, 32);
    assert_eq!(convergence.fine_elements, 64);
    assert!(convergence.relative_difference >= 0.0);
    assert!(convergence.target == MAXWELL_BEM_TARGET);
    let mut tighter = scene.clone();
    tighter.elements = 128;
    let tighter = solve_bem(&tighter).expect("tighter square");
    assert!(tighter.convergence().relative_difference <= convergence.relative_difference + 1e-12);
}

- [ ] **Step 3: Implement the bounded BEM**

- Reject `Conductor2D` outside 2D sampling.
- `elements` is fine, even `32..=256`; coarse exactly `elements / 2`.
- Constant-density panels, midpoint collocation, Green's function, Gaussian elimination with the documented pivot threshold; return `Unavailable(IllConditioned)` on singular/nonfinite.
- Boundary potential `-E0·x`; compute `Q` and reject `Unavailable(NetChargeMode)` when `|Q| > 1e-6*max(|E0|*extent,1)`.
- Probe ring `R_probe=4*max(outline_extent,1e-6)`, 8 points, global normalization `max_probe(max(|E_fine|,|E0|,1e-9))`. If coarse == fine, `AccuracyNotMet` with no TargetMet. If coarse/fine nonfinite, `Unavailable`.
- `BemSolution::field_at` is total field. `sample_maxwell_with_bem` uses it for Conductor2D; `sample_maxwell` calls `solve_bem` for pure tests.
- Keep solver storage bounded by `N²` dense matrix and work `N³` below the cap. Do not add an iterative solver.
