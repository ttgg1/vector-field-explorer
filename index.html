What to try

  • Firefox: WebGPU is available in Firefox 141+ on Windows, Firefox 145+ on macOS Tahoe ARM, and Firefox Nightly on Linux. Check about:config → dom.webgpu.enabled if that setting is present, and update Firefox to a supported version.
  • Chrome or Edge: WebGPU is available in Chrome and Edge 113+. If it is disabled, open chrome://flags/#enable-unsafe-webgpu or edge://flags/#enable-unsafe-webgpu and enable it.
  • Linux Chromium: WebGPU may need --enable-features=Vulkan and a working Vulkan driver. See the Chrome WebGPU documentation.

Learn more: MDN WebGPU API, caniuse: WebGPU, and your browser's WebGPU support.

If WebGPU is unavailable, use the native desktop build.
